# Sketchup Open XRef Manager 

Open XRef Manager is an external reference (XRef) system for SketchUp. This plugin is designed to supercharge your collaborative workflows, allowing teams to work on different parts of a project in separate files while maintaining a live, synchronized link between them.

Key features include:
- A powerful XRef Manager window to view the status of all linked files.
- A robust Check-in / Check-out locking system to prevent team members from overwriting each other's work. Xref components that are checked out by another user will get locked until they are checked back in again.
- Automatic prompts and background monitoring for a seamless, intuitive workflow.
- Flexible path management with support for both absolute and relative paths.
- A dedicated toolbar and integrated right-click context menus for quick access to all features.
